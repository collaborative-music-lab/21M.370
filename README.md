# Getting Started

## PlugData

We will be using [PlugData](https://plugdata.org), a port of the common PureData software. Download PlugData and install.

## Github Repository

This repository will contain all of class examples and lectures. I recommend you:

1. Make a github account
2. Download github desktop
3. Log into Github Desktop
4. Clone this repository
5. Make sure to pull from the repository before every class

## Thonny and CircuitPython

We will be using CircuitPython on the ESP32, and I recommend you program it using [Thonny](https://thonny.org). Download and install.
